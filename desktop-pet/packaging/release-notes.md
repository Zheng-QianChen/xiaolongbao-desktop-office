任务运行时记录原窗口，点击时重新查询当前 Cursor 运行实例。原窗口关闭、同名工作区或多个尚未建立归属的窗口无法唯一定位时，会提示原因并保留未读，不擅自选择另一个窗口。此定位适配 Windows Cursor 3.14；外部软件更新后可能需要调整。

窗口查询在后台执行，桌宠动画和任务观察继续运行。跳转不伪造已读；已读仍以 Cursor 自己的状态为准。
