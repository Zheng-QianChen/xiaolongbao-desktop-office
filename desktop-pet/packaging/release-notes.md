小笼包桌面事务所 0.1.2 Windows 预览版。

桌面版接入断线动画：推开电脑、趴下、冒出小幽灵。重复断线通知不会重播，恢复连接后继续工作；同步接入转身返回工位、步行归队和大包子已读后与猫咪下棋的成品动作。

Codex、Cursor、ZCode 会话归档后，小包子收工离开并释放工位，即使还有未读标记也不会留下。归档不修改原软件的已读状态；断线或迟到的蓝点不会复活归档任务。本地通知桥新增 archived / unarchived 事件供其他接入使用。

修正工位小包子的已读动作角色，避免调用大包子的下棋位移。断线电脑和状态文字保留足够留白。

保留原安装标识、数据目录和 WangBun 命令行入口，兼容 0.1.0 的设置与接入配置。

- 安装版和免安装版，无需另装 Python。
- 多 Agent 共用小屋工位，收工分身全局叠叠归队。
- 自由拖动、移动锁定、缩放、右键菜单和会话跳转。
- 本地通知桥、MCP、RSS/邮箱订阅、可选 OpenAI 兼容助手。
- 用户数据独立存储，退出关闭自己的本地桥。
