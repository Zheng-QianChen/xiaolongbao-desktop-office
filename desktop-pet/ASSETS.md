# 角色与素材说明

望包 / 小笼望是以《明日方舟》角色「望」为灵感的非官方同人桌宠。本项目与游戏官方没有隶属或授权合作关系。角色及原作相关权利归相应权利人所有。

程序代码的 MIT 许可不覆盖角色形象、`assets/` 图片、`layered-poc/layers/` 图片以及 `rig.json`、`spatial-rig-v7.json` 中的角色造型数据，也不授予原作角色或商标权利。不要将代码许可理解为这些素材可自由商用或再许可。

项目制作使用了 AI 辅助编程、图像生成及后续分层、裁切、动画和交互调整。仓库保留运行所需的成品素材，不包含私人对话、原始参考资料、制作历史或本机运行记录。

技能「取势」「连星」「天下劫」的图标参考来自 [PRTS「望」资料页](https://m.prts.wiki/w/%E6%9C%9B)。相关图像仍归原权利人。源码中的几何绘制和动作实现与这些素材的权利范围分别处理。

如果权利人需要更正署名或处理某项素材，请通过仓库 Issue 联系维护者。

## 动作接入情况（0.1.2）

网页运行版使用外观工程的分层渲染器。桌面版通过透明 PNG 帧播放，基础动作沿用 v9 素材；本次从外观工程 v8 的成品中接入 246 帧，保存于 `assets/animation-frames-v10/`。

| 素材 | 网页版 | Windows 桌面版 |
| --- | --- | --- |
| 断线：推开电脑、趴下、灵魂与 Wi-Fi | 已接入 | 本次接入 60 帧；播完保持，恢复连接后继续工作 |
| 转身、背向返回工位 | 已接入 | 本次接入 54 帧 |
| 转向大包子并步行归队 | 已接入 | 本次接入 36 帧 |
| 已读落稳、猫咪与包子下棋 | 大包子专用 | 本次接入 96 帧，大包子专用 |
| 工作、喝水、眨眼、等待、合盖、失败、眼镜彩蛋 | 分层动画 | 已有 v9 帧动画，尚未全部替换为分层版 |

围巾换装仍是外观预览功能，正式软件尚无换装入口。PSD、历史版本和 Blender 空间参考文件属于制作资源，没有作为额外动作载入；当前成片不使用 3D 网格。v10 保留原导出的 480×440 画布及 (55,130) 原点，避免裁掉灵魂、电脑和棋盘。
